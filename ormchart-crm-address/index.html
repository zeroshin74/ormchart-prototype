2콤보박스 트리거 (입력형)항상placeholder 발송 지역 선택 — 지역명 검색해서 추가 (예: 강남구, 역삼동). 클릭·포커스·타이핑 즉시 패널 5 열림 — 누른 자리에서 바로 검색. 닫힐 때 검색어 자동 초기화(선택 결과는 칩이 표현). role="combobox" aria-expanded aria-autocomplete="list"
3캐럿 토글 ▾항상패널 열기/닫기 토글. 입력창 클릭은 열기만 하고 닫지 않으므로(텍스트 편집과 충돌) 마우스 닫기는 캐럿·바깥 클릭·취소·적용으로.
4지도로 확인 버튼항상 (적용 선택 0곳이면 disabled)적용된(committed) 선택의 범위를 지도 모달 8로 확인. 확인할 범위가 없으면 비활성 + title 안내.
5a브레드크럼패널 열림 + 검색어 없음‹ 상위 복귀 · 전국 › 시/도 › 시/군/구 세그먼트 클릭으로 해당 깊이 점프. 검색 중에는 숨김.
5b지역 목록패널 열림드릴 모드(검색어 없음): 현재 깊이의 하위 목록. 체크박스=그 지역 전체 선택, 행/›=하위 진입. 검색 모드: 전체 경로 대상 토큰 매칭 결과를 평면 나열(경로+단위 태그), 행 클릭=선택 토글. tri-state: 전체 ☑ / 부분 ⊟(aria-checked="mixed") / 없음 ☐. 항목을 선택해도 패널은 닫히지 않는다.
5c포함/제외 토글초안 선택 ≥ 1곳포함=선택 지역에 발송, 제외=선택 지역만 빼고 발송. 선택이 모두 해제되면 포함으로 리셋 후 숨김.
5d패널 푸터패널 열림좌: 선택 N곳(축약 단위 기준) + 모두 지우기. 우: 취소(초안 폐기)/적용(확정). 적용을 눌러야만 칩·요약에 반영.
6칩 영역적용 선택 ≥ 1곳선택 단위별 칩. 상위 단위는 강남구 전체로 축약(하위 전부 선택 시 자동 승격). 제외 모드: 빨강 + 취소선 + −. ✕=개별 제거(즉시 반영). hover 시 전체 경로+법정동코드 툴팁. 인원수 미표기.
7범위 요약적용 선택 ≥ 1곳자연어 한 줄: 서초구 전체 · 강남구 2개 동 제외하고 발송. 같은 구의 동들은 N개 동으로 묶고, 4구 초과 시 외 N곳 축약.
8지도 모달버튼 4 클릭확인 전용 — 지도에서 선택 불가. 선택과 관련된 시/군/구만 점선 구역으로 자동 구성(팬/줌 불필요). 포함: 선택 동=파랑, 같은 구 나머지=중립. 제외: 선택 동=빨강, 같은 구 나머지=파랑(실제 발송 대상). 우측: 적용 선택의 전체 경로 목록(지도 표기 밖 지역 보완). 닫기: 버튼·✕·Esc·바깥 클릭.

S3패널 · 선택 진행초안 선택 ≥ 1곳S1/S2에 포함/제외 토글 5c 추가 노출. 상위 tri-state ⊟ 연동. 패널은 계속 열림.
S4적용됨적용 클릭패널 닫힘 + 칩 6 + 요약 7 갱신 + 지도 버튼 활성. 취소/Esc는 초안 폐기(S0 또는 이전 S4 유지).
S5지도 확인S4에서 4 클릭모달 8. 조작 불가(보기 전용), 닫기만 가능.

03선택 모델 규칙 (개발 구현 기준)

규칙정의
선택 단위법정동코드 prefix의 집합 Set<code> (레벨 혼합 허용: 2/5/10자리)
커버 판정노드가 선택됨 = 자기 코드 또는 조상 코드가 집합에 존재 (code.startsWith(prefix))
축약 (collapse-up)어떤 부모의 모든 자식이 선택되면 자식들을 제거하고 부모 코드 1개로 치환 → 칩 강남구 전체. 상위로 반복 적용.
분해 (explode)부모가 선택된 상태에서 하위 1개를 해제하면, 부모를 제거하고 해제 경로를 제외한 형제들을 선택으로 재구성.
발송 대상 계산포함 = 환자 법정동코드가 선택 prefix 중 하나로 시작(OR). 제외 = NOT(OR). 성별·연령·출생연도와 AND 결합.
미선택집합이 비면 주소 조건 자체가 없음(모드는 포함으로 리셋).
