치료 결과홍길동 · M/58 · 2026-07-13

다른 환자 차트 조회 중 — 김영희 (F/45)

치료 결과 화면을 벗어난 상태입니다. 재진입하면 사용자별로 저장된 마지막 펼침 상태가 복원됩니다.
저장하지 않은 소견 입력값은 실제 화면과 동일하게 유지되지 않습니다.

Interaction Spec

  • 보기 드롭다운(최상단) — 기본 보기: 모든 섹션 카드 열기 + 각 섹션 행을 기본값으로 리셋(기초검사 펼침, 나머지 접힘) · 모두 펼치기: 8개 섹션 카드 모두 열기(행 상태 유지) · 모두 접기: 8개 섹션 카드 모두 닫기(헤더만 표시)
  • 섹션 헤더 ▼/▶ — 해당 섹션 카드 열기/닫기. 테이블 목록 전체가 숨겨지고 헤더만 남음
  • 타이틀 옆 토글 버튼 — 해당 섹션의 행 상세 전체를 펼치기/접기. 레이블은 "펼치기"/"접기"로 표기하며("모두"는 우상단 드롭다운 전용), 행이 하나라도 펼쳐져 있으면 "접기"로 표시. 테이블 목록은 항상 유지
  • 상태 텍스트 — 펼침 기능이 있는 행은 ▶/▼ + 밑줄 텍스트로 표시되며 클릭 시 해당 행의 상세가 열리고 닫힘. 펼침 기능이 없으면(주사·진단의학 단문형/수치형) 색상 텍스트만 표시
  • 빠른 입력 칩(치료) — 클릭 시 치료 소견에 문구가 추가되고 바이트 카운터가 갱신됨
  • 기본값 정책 — 주사: 펼침 없음 · 진단의학: 단문형/수치형 없음, 장문형 접힘 · 기초검사: 펼쳐짐 · 치료/영상의학/내시경/수술처치/기능검사: 접힘. 저장된 상태가 없는 최초 진입에만 적용되는 초기값
  • 상태 유지 (TO-BE) — 섹션 카드 열림/닫힘과 행 상세 펼침 상태가 조작 즉시 사용자별로 저장되어, 화면 이탈 후 재진입 시 그대로 복원됨 (환자 단위 아님). 최초 조작 시 1회 안내 토스트 표시. 저장하지 않은 소견 입력값은 유지 대상이 아님
  • 기본 보기 = 리셋 — 저장된 상태와 무관하게 정책 기본값으로 복귀하며, 그 기본값 상태가 새 저장값이 됨. 상태가 낯설어졌을 때의 탈출구 역할
