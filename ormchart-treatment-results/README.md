# ORMCHART 치료 결과 화면 — 인터랙션 프로토타입

치료 결과 화면의 오더분류별 펼침/접힘 정책과 **사용자별 상태 유지(TO-BE)** 를
실제로 조작해 볼 수 있는 단일 HTML 프로토타입입니다.
빌드나 의존성 없이 `index.html` 하나로 동작합니다.

## 실행 방법

- 로컬: `index.html`을 브라우저로 열기
- GitHub Pages: 저장소 Settings → Pages → Branch를 `main`(root)으로 설정하면
  `https://<계정>.github.io/<저장소>/` 로 바로 공유 가능

## 화면 구성

섹션 순서: 치료 → 주사 → 진단의학(단문형/수치형/장문형) → 기초검사 → 영상의학 → 내시경 → 수술/처치 → 기능검사

| 오더분류 | 행 펼침 기능 | 기본값 |
|---|---|---|
| 치료 | 있음 | 접힘 |
| 주사 | 없음 | — |
| 진단의학 · 단문형/수치형 | 없음 | — |
| 진단의학 · 장문형 | 있음 | 접힘 |
| 기초검사 | 있음 | **펼쳐짐** |
| 영상의학 / 내시경 / 수술·처치 / 기능검사 | 있음 | 접힘 |

## 인터랙션 정의

- **보기 드롭다운(우상단)** — `기본 보기`: 모든 섹션 카드 열기 + 행 상태를 기본값으로 리셋 ·
  `모두 펼치기`: 8개 섹션 카드 모두 열기(행 상태 유지) · `모두 접기`: 8개 섹션 카드 모두 닫기(헤더만 표시)
- **섹션 헤더 ▼/▶** — 해당 섹션 카드 열기/닫기
- **타이틀 옆 토글 버튼** — 해당 섹션의 행 상세 전체를 `펼치기`/`접기`
  ("모두" 표기는 우상단 드롭다운 전용). 행이 하나라도 펼쳐져 있으면 `접기`로 표시
- **상태 텍스트** — 펼침 기능이 있는 행은 ▶/▼ + 밑줄 텍스트, 클릭 시 상세가 열리고 닫힘.
  펼침 기능이 없으면(주사, 진단의학 단문형/수치형) 색상 텍스트만 표시
- **치료 상세 폼** — 시작/종료 시간 + 빠른 입력 칩 + 치료 소견을 하나의 폼으로 구성.
  칩 클릭 시 소견에 문구가 추가/제거되고 바이트 카운터가 갱신
- **버튼 컬러** — `결과완료` Dark Gray(#374151), `수행완료` Blue(#378ADD)

## 상태 유지 시뮬레이션 (TO-BE)

상단 SIMULATION 바에서 `① 화면 조작 → ② 화면 나가기 → ③ 재진입` 흐름을 재현합니다.

- 행 펼침/섹션 토글/카드 열림 상태가 조작 즉시 **사용자별**로 저장됨 (환자 단위 아님)
- 최초 조작 시 1회 안내 토스트: "펼침 상태가 저장되었습니다 — 화면을 나갔다 와도 유지됩니다"
- 화면 이탈 후 재진입하면 저장된 마지막 상태가 그대로 복원됨 (localStorage — 실제 새로고침에도 유지)
- `기본 보기` 선택 = 리셋: 저장 상태와 무관하게 정책 기본값으로 복귀하는 탈출구
- 저장하지 않은 소견 입력값은 유지 대상이 아님

- Accent `#378ADD` · 보더 `0.5px #D7DCE1` · 카드 radius 8px · 그림자 `0 1px 2px rgba(0,0,0,0.04)`
