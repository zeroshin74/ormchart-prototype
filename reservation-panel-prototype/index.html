화면 ID: RSV-LEFT-01 · Ver 1.1 · 작성일 2026-07-14 · 본 가이드는 [프로토타입] 탭과 동일 사양이며, 프로토타입에서 모든 인터랙션을 직접 확인할 수 있습니다.

1. 개요

목적예약설정 화면 좌측 패널의 모듈 구성과 세로 리사이즈 인터랙션 동작 정의 (기획·개발 공용)
적용 범위좌측 패널 내 ① 모듈 표시 스위치 ② 캘린더 ③ 공유사항 ④ 캘린더 설정 ⑤ 숨긴 캘린더 목록 ⑥ 하단 고정 버튼
전제 조건공유사항은 설정 ON 시에만 노출됩니다. 숨긴 캘린더 목록은 항목이 없을 수 있습니다(영역 미노출 가능).
비고간격·크기·형태·색상 등 GUI 상세 수치는 본 문서에서 다루지 않으며, 별도 GUI 디자인 가이드에서 제공 예정입니다.

3. Default 높이 분배 정책

적용 시점: 최초 진입, ① 스위치 ON/OFF, 스플리터 더블클릭(리셋). 아래는 상대 비율 기반의 동작 정책이며, 기준이 되는 절대 수치(캘린더 한 달 높이 등)는 GUI 가이드를 따릅니다.

모듈Default 높이 정책
③ 공유사항min(가변 영역의 1/3, 콘텐츠 전체 높이)로 등장 — 글자 수(100자)는 줄바꿈에 따라 렌더링 높이가 달라져 높이 기준이 될 수 없으므로, 비율 상한 + 콘텐츠 클램프로 정의(균형 규칙). 콘텐츠가 짧으면 콘텐츠 높이만 차지하고, 1/3 몫보다 길면 default에서는 내부 스크롤로 접근하며 확대(INT-03)·드래그로 전체를 볼 수 있음. 확장에는 최대 제한이 없으며, 다른 모듈과 동일하게 콘텐츠보다 커지면 하단 여백이 발생함
⑤ 숨긴 캘린더 목록콘텐츠 높이(목록 전체가 보이는 높이, 하단 여백 0)
④ 캘린더 설정위 두 모듈 배분 후 나머지 공간 전부
  • 노출 모듈이 2개 이하일 때도 동일 규칙 적용, 규칙 대상이 아닌 조합(예: 공유사항 OFF)은 균등 분배 후 잉여를 캘린더 설정에 배분.
  • 공간이 부족하면 모듈 최소 높이(타이틀 + 콘텐츠 1줄) 확보가 항상 우선합니다.
  • 공유사항 확장 정책: 축소·확장·드래그·더블클릭 모든 조작 문법이 다른 모듈과 동일합니다. 확장 최대 제한이 없어 콘텐츠보다 크게 늘리면 하단 여백이 발생할 수 있습니다. 콘텐츠 기준(콘텐츠 높이·비율 클램프)은 default 등장 높이에만 적용됩니다.

4. 인터랙션 명세

ID트리거동작제약 · 예외
INT-01모듈 사이 여백(스플리터) 드래그경계 위/아래 모듈 높이 증감. hover 시 드래그 핸들과 리사이즈 커서 노출로 조절 가능함을 인지시킴. 인접 모듈이 최소 높이에 도달하면 그 다음 모듈에서 마저 차감(캐스케이드) → 한 모듈을 최대까지 확장 가능.모든 모듈이 최소 높이면 더 줄지 않음. 한계 도달 시 핸들 상태 변화로 피드백.
INT-02스플리터 더블클릭§3 Default 분배로 리셋.—
INT-03타이틀 우측 확대/복원 버튼 클릭해당 모듈 최대화(나머지 모듈은 최소 높이). 재클릭 시 확대 직전 레이아웃으로 복원. 아이콘: 확대 ↔ 복원 상태 전환. 세 모듈 모두 동일하게 동작하며, 콘텐츠보다 크게 확장되면 하단 여백이 발생할 수 있음.아이콘 상태는 높이 기반 판정 — 드래그로 최대에 도달해도 복원 아이콘으로 동기화(이때 복원은 Default 분배). 노출 모듈이 1개면 동작 없음.
INT-04① 스위치 ON/OFF해당 모듈 노출/숨김 + 노출 모듈을 §3 규칙으로 재분배. 스플리터는 인접한 노출 모듈 사이에만 1개씩 표시.마지막 남은 모듈이 가변 영역 전체 사용.
INT-05캘린더 1개/2개 토글한 달 캘린더의 높이는 1개/2개 모드에서 동일. 2개 모드에서는 캘린더 영역이 좌측 패널 전체 높이의 1/2을 차지하며, 1개 모드는 그 절반(약 1/4)만 차지. 전환 시 가변 영역이 남은 높이로 재계산(기존 비율 유지).공유사항 default 크기는 캘린더 표시 모드와 무관하게 동일.
INT-06모듈 내부 휠/트랙패드 스크롤콘텐츠 세로 스크롤. 위/아래 잘린 내용이 있으면 페이드로 힌트 표시.최소 상태(1줄)에서도 스크롤 동작. 스크롤바 영역은 상시 확보하여 스크롤바 유무로 본문 줄바꿈이 변하지 않아야 함.
INT-07스플리터 키보드 조작Tab으로 포커스 → ↑/↓ 키로 일정 단위 조절.포커스 상태를 시각적으로 표시.
INT-08창 높이 부족(모든 모듈 최소 합 초과 불가)모든 모듈을 최소 높이(타이틀+1줄)로 고정. 모듈 전체를 감싸는 별도 스크롤은 제공하지 않으며, 콘텐츠 접근은 각 모듈 내부 스크롤(INT-06)로 처리.최소 지원 해상도는 GUI 가이드에서 정의.

5. 상태 정의

5-1. 가변 모듈 상태

상태정의
Default§3 규칙으로 배분된 초기 상태
Custom사용자가 드래그로 조정한 상태 (INT-01)
Min최소 높이 = 타이틀 + 콘텐츠 1줄. 더 이상 축소 불가
Max해당 모듈 외 모든 노출 모듈이 Min인 상태. 버튼이 복원 아이콘으로 전환

5-2. 확대/복원 버튼 상태

  • 확대: 모듈이 Max가 아닐 때. 클릭 → 최대화
  • 복원: 모듈이 Max일 때. 클릭 → 직전 레이아웃(드래그로 Max 도달한 경우는 Default 분배)

6. 접근성 · 개발 참고

  • 스플리터: role="separator" + aria-orientation="horizontal", Tab 포커스 및 방향키 조절(INT-07)
  • 스위치: button + aria-pressed, 확대/복원 버튼: aria-label로 모듈명 포함
  • 모든 조작 요소에 키보드 포커스 표시 제공, 모션 최소화 설정(prefers-reduced-motion) 대응
  • 구현 참고: 컨테이너 리사이즈 감지(ResizeObserver)로 재배분, 드래그는 pointer capture 사용, 모듈 높이 합계가 가변 영역을 넘지 않도록 정수 스냅 처리
