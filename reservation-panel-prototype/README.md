# 예약 캘린더 좌측 패널 — 리사이즈 인터랙션 프로토타입

병원 예약설정 화면 좌측 패널의 모듈 리사이즈 인터랙션을 검증하기 위한 단일 HTML 프로토타입입니다.
외부 의존성 없이 `index.html` 파일 하나로 동작합니다.

상단 탭으로 두 화면을 전환할 수 있습니다.

- **프로토타입** — 실제로 조작 가능한 인터랙티브 데모
- **화면설계서** — 기획자·개발자용 UX·Interaction 동작 가이드 (영역 정의, Default 분배 규칙, 인터랙션 명세 INT-01~07, 상태 정의, 접근성). 간격·크기·색상 등 GUI 상세 수치는 별도 GUI 디자인 가이드에서 제공 예정

## 실행 방법

- `index.html`을 브라우저에서 바로 열면 됩니다. (빌드·서버 불필요)
- GitHub Pages로 배포하려면: 저장소 **Settings → Pages → Branch: main / root** 선택 → `https://<계정>.github.io/<저장소>/` 에서 확인

## 화면 구성

| 영역 | 동작 |
|---|---|
| 상단 스위치 바 | 공유사항 / 숨긴 캘린더 목록 ON·OFF |
| 캘린더 (고정) | 우측 토글로 1개/2개 전환, 드래그 리사이즈 대상 아님. 한 달 높이는 두 모드에서 동일 — 2개 모드는 패널 전체 높이의 1/2, 1개 모드는 약 1/4 차지 |
| 공유사항 · 캘린더 설정 · 숨긴 캘린더 목록 | 가변 영역 — 아래 인터랙션 스펙 참조 |
| 하단 버튼 2개 | 항상 고정 (예약 미확정 환자, 취소/부도내역) |

## 인터랙션 스펙

### Default 높이 분배 정책
- **공유사항**: **min(가변 영역의 1/3, 콘텐츠 전체 높이)**로 등장 — 글자 수(100자)는 줄바꿈에 따라 렌더링 높이가 달라져 높이 기준이 될 수 없으므로 '비율 상한 + 콘텐츠 클램프'로 정의. 콘텐츠가 1/3 몫보다 길면 default에서는 내부 스크롤로 접근. 확장은 다른 모듈과 동일하게 **최대 제한 없음**(콘텐츠보다 커지면 하단 여백 발생)
- **숨긴 캘린더 목록**: 콘텐츠 높이만큼만 (하단 여백 0)
- **캘린더 설정**: 나머지 공간 전부
- 모듈 ON/OFF 토글 시 위 정책으로 재분배
- 기준 절대 수치는 별도 GUI 가이드에서 정의

### 리사이즈
- 모듈 사이 여백을 **드래그**해 높이 조절 (hover 시 핸들 표시, `row-resize` 커서)
- 최소 높이 = **타이틀 + 콘텐츠 1줄(80px)**, 그 이하로는 줄어들지 않음
- 인접 모듈이 최소에 도달하면 그 너머 모듈에서 마저 줄어드는 **캐스케이드** 방식
- 한계 도달 시 핸들이 붉게 변해 피드백
- **더블클릭** = 균등 분배 리셋
- 키보드: 스플리터 포커스(Tab) 후 ↑/↓ 로 16px 단위 조절

### 스크롤
- 각 모듈 내부 세로 스크롤, `scrollbar-gutter: stable`로 스크롤바 유무와 무관하게 줄바꿈 고정
- 잘린 내용이 있으면 상·하단 페이드 그라데이션으로 힌트 표시
- 최소 상태(1줄)에서도 휠 스크롤 동작

### 예외 처리
- 창 높이가 모듈 최소 높이 합보다 작아지면 모든 모듈을 최소 높이로 고정
- 모듈 전체를 감싸는 외부 스크롤은 제공하지 않으며, 콘텐츠 접근은 각 모듈 내부 스크롤로 처리
