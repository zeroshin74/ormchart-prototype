# 인바디 결과 분석 v2 — 신규 그래프 프로토타입

피그마 신규 스펙( `Untitled` / node `35-2` )의 정책·UI·인터랙션 가이드라인을 반영해
기존 `inbody-dashboard`(React+Vite)를 대체하는 **독립형 HTML 프로토타입**으로 신규 제작.
Node.js/빌드 도구 없이 브라우저에서 바로 열립니다.

## 실행

정적 서버로 이 폴더를 서빙하거나, `index.html`을 브라우저로 열면 됩니다.

```bash
ruby -run -e httpd /Users/sintaegon/Documents/Test02/inbody-v2 -p 5188
```

## 파일 구성

- `index.html` — 마크업 (타이틀바/환자헤더/컨트롤바/메인)
- `styles.css` — 스타일
- `data.js` — Mock 데이터 (환자 이요원, 3년치 방문 55회: 2023-09~2026-08, 지표 7종, 처방 4종)
- `app.js` — 렌더링 + 인터랙션 전체 로직

## 구현된 신규 스펙 (피그마 가이드라인 매핑)

### 항목별추이 — 리스트형
- 단일 X축: 하단 처방항목 날짜 헤더가 유일한 시간축. 상/하단 좌측 고정영역 폭 동일(`--left-col-w`), 데이터 포인트↔날짜 셀 수직 1:1 정렬(모든 스크롤 컨테이너의 내부폭-뷰포트폭을 동일하게 구성해 scrollLeft 하나로 동기화)
- 스케일 4단계(25/50/75/100%) — 75% 기본뷰, 25%는 Fit(측정한 날만 표시)
  - 날짜 라벨 단위 자동(일/주/월/분기) + 충돌 시 생략, 첫 측정일·오늘 라벨 절대 유지
  - 값 라벨: 100/75% 전체, 50% 충돌 시 최고/최저/최근만, 25% 숨김(호버로 확인)
  - 처방 셀: 셀 폭 45px 이상 `용량|일투수|일수`, 미만 용량 단독, 최소 간격 16px
- 줌: 즉시 전환(애니메이션 없음), 한계 단계 버튼 Dim, 기본 우측(최신) 앵커,
  포인트 클릭 시 해당 지점이 새 줌 기준점(클릭 앵커링)
- 호버: 상단 차트→하단 테이블 관통형 1px 점선 크로스헤어, 상/하단 툴팁 동시 노출,
  툴팁은 화면 최상위 레이어(클리핑 없음), 하단 툴팁 우선 + 타겟 툴팁 최상위 z-index
- 실선 고정(측정 간격 무관), 단 1회 측정 지표(체세포량)는 Ring+Halo 강조

### 항목별추이 — 카드형
- 2열 그리드, 카드별 **개별 X축**(카드 폭 기준 자체 지오메트리+라벨)
- 관통 크로스헤어 미사용 — 날짜 논리 동기화: 카드 하나 호버 시 전체 카드 동일 날짜에
  독립 크로스헤어+툴팁, 하단 테이블 동일 날짜 강조선/셀 하이라이트

### 지표 변화 비교
- 진입 시 Fit to screen 기본. 3단 구성: 중앙 인덱스 차트(100=기준일) / 우측 미니맵(항상
  전체기간 Fit 고정) / 하단 처방 테이블(중앙 차트와 물리 폭 1:1)
- 줌은 중앙+하단에만 적용, 우측 패널 스케일 잠금
- 중앙↔하단 물리 크로스헤어, 중앙↔우측 논리 동기화(동일 날짜 점선+미니 툴팁 동시)
- 범례 클릭으로 지표 토글

### 피드백 반영 정책 (2차)
- 연도 표시: 날짜 라벨 위 **연도 밴드**(간트 헤더 방식) — 연도 구간 시작에 라벨,
  스크롤 시 구간 내 sticky 클램프, 연도 경계에 세로 구분선
- 날짜 중첩 방지: 라벨 **실측 텍스트 폭** 기반 충돌 계산으로 생략(Skip),
  우선순위 = 양끝 기준 라벨 > 측정/처방일 > 달력 그리드
- 처방 셀 표기(스케일 기준): 75~100%는 `용량|일투수|일수` 전체 노출 + 호버/어포던스 없음,
  25~50%는 용량 단독 칩(pill)+점선 밑줄 어포던스 + 호버 툴팁.
  처방 툴팁은 25~50%·생략 컬럼·노트 보유·접힘 상태에서만 노출
- 처방항목 전체 접기/펼치기: 버튼형 토글(테두리+회전 셰브론) + 타이틀 행 클릭,
  접힘 시에도 X축(날짜 헤더)은 유지
- 지표변화비교 범례는 차트 타이틀 행 우측 배치, 비교 차트에서는 단일 측정
  Ring 강조 제거(항목별 추이에서만 유지)
- 처방항목 테이블을 차트 카드와 동일한 카드 스타일(14px 거터+테두리)로 좌우 정렬 통일

### 날짜 축·처방 표기 정책 (3차 — 최종)
- 날짜 축은 처방항목 타이틀과 분리된 **독립 행**(연도 밴드 + 한 줄 날짜 + 틱)이며,
  타이틀 행은 축 아래에 위치. 하단 블록(스크롤바+축+타이틀+테이블)은 sticky로
  항상 화면에 노출
- 날짜 라벨은 **무조건 한 줄**. 단위 사다리 `일 → 주 → 월(숫자만) → 분기(숫자만) →
  연도+틱만` × 폰트 `11 → 10 → 9px` 순서로 시도해 무충돌인 첫 조합 채택
- 처방 이벤트는 전부 표시하되 밀도에 따라 3단계:
  간격 45px↑(75~100%) `용량|일투수|일수` → 20px↑ 용량 칩 → 미만 **원형 점**(7px 솎아냄).
  전체 텍스트 셀만 호버/툴팁 없음
- 축 표기 대상: 항목별 추이의 공유 축=처방일만, 카드 개별 축=측정일만,
  지표 변화 비교=측정일+처방일 통합

### 기존(구버전) 대비 보완 인터랙션
- 마우스 휠 줌(커서 날짜 앵커) / 가로 휠·트랙패드 팬
- 드래그 패닝(grab 커서) + 마스터 가로 스크롤바(sticky)
- 툴팁 핀 고정(클릭)·✕ 닫기·캔버스 클릭 해제, 핀 중 호버 무시
- 가장자리 인식 툴팁 배치(좌/우 플립 + 화면 클램프)
- 기간 프리셋(1/3/6개월·1년·전체) + 직접 날짜 조회, 표시 지표 설정 팝오버
- 처방 이벤트 임상 노트(시작/증량/보류/재개 등) 툴팁 표기
